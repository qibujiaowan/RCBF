## 一、这篇论文解决什么问题？

### 背景：强化学习用于安全关键系统的核心矛盾

强化学习（RL）训练的本质是**试错探索**——智能体需要访问足够多的"状态-动作"对才能学到好的策略。这个过程在游戏或仿真中代价很低，但在真实机器人系统中，探索过程可能经过**不安全的状态**（碰到障碍物、超速、侧翻等），代价不可接受。

现有的解决思路大致分两类：

- **训练结束后再保证安全**（如 CPO、PPO-Lagrangian）：只在最终策略上满足约束，训练过程不管。
- **训练过程中保证安全**（本文所属的方向）：在每一步探索中都不进入危险状态。

本文属于第二类，采用**控制屏障函数（CBF）作为安全过滤层**的路线。但在这条路线上，已有的工作（以 Cheng 2019 为代表）存在三个具体问题：

1. 只支持仿射形式的 CBF（即 $h(x) = p^\top x + q$），表达能力非常有限；
2. 用神经网络去近似 CBF 层的行为，近似本身带来新的误差；
3. 安全层对 RL 输出的修改没有被纳入策略梯度的更新中，导致 RL 把安全层的行为视为"未知动力学"，训练困难。

**本文的目标：同时解决这三个问题。**

---

## 二、核心思路：三句话概括

1. 用**鲁棒控制屏障函数（RCBF）**处理模型不确定性，用高斯过程（GP）在线学习未知扰动，使安全保证对模型误差鲁棒；
2. 将 RCBF 安全层做成**可微分的 QP 层**，使策略梯度能够直接对"最终安全输出"负责，而不是对"RL 原始输出"负责；
3. 提出**约束无关任务学习**，使价值函数不被训练时的特定约束污染，支持零样本迁移到不同约束场景。

## 三、系统模型与问题设定

### 3.1 带扰动的控制仿射系统

论文考虑的系统模型为：

$$\dot{x}(t) = f(x) + g(x)u(x) + d(x)$$

其中：
- $f(x)$：已知的漂移动力学（drift dynamics）
- $g(x)$：已知的输入矩阵（控制增益）
- $d(x)$：**未知的连续确定性扰动**（可理解为建模误差、外部干扰等）
- $u(x)$：控制输入

**重要前提**：$f$ 和 $g$ 是已知的（即标称模型已知），只有 $d$ 是未知的。这不是完全的无模型方法，而是"标称模型已知 + 扰动未知"的半模型方法。

### 3.2 安全集合

安全集合定义为某个函数 $h(x)$ 的超水平集：

$$\mathcal{C} = \{x : h(x) \geq 0\}$$

目标是保证系统状态始终在 $\mathcal{C}$ 内，即 $h(x(t)) \geq 0$ 对所有时刻成立。

## 四、技术核心：鲁棒控制屏障函数（RCBF）

### 4.1 标准 CBF 的局限

标准 CBF 的安全条件为：

$$\dot{h}(x, u) = \nabla h \cdot [f(x) + g(x)u] \geq -\alpha(h(x))$$

这个条件依赖精确的系统动力学 $f, g$。一旦存在扰动 $d$，实际的 $\dot{h}$ 会偏离这个条件，安全保证失效。

### 4.2 RCBF 如何处理扰动

论文将扰动建模为一个**集合值映射**（set-valued map）：

$$\dot{x}(t) \in f(x) + g(x)u(x) + D(x)$$

其中 $D(x)$ 是扰动的可能范围（凸包）。

RCBF 的安全条件在标准 CBF 的基础上，额外减去扰动的最坏情况影响：

$$\nabla h \cdot [f(x) + g(x)u] \geq -\alpha(h(x)) - \underbrace{\min_{d \in D(x)} \nabla h \cdot d}_{\text{最坏情况扰动项}}$$

**直观理解**：标准 CBF 要求"在无扰动时不离开安全集"，RCBF 要求"即使在最坏情况的扰动下也不离开安全集"。条件更严，但安全保证更强。

### 4.3 用高斯过程学习扰动集合

扰动 $d(x)$ 未知，但可以通过观测数据估计。具体方法：

**数据收集**：在探索过程中，记录每一步的测量值：
$$y^{(i)} = \hat{\dot{x}}^{(i)} - f(x^{(i)}) - g(x^{(i)})u^{(i)}$$
这个残差就是扰动的观测噪声样本。

**GP 训练**：对状态空间的每个维度独立训练一个高斯过程，得到每个状态点处扰动的均值 $\mu_d(x)$ 和标准差 $\sigma_d(x)$。

**扰动集合估计**：
$$[D(x)]_d = [\mu_d(x) - k_c\sigma_d(x),\ \mu_d(x) + k_c\sigma_d(x)]$$

其中 $k_c$ 是置信度参数（例如 $k_c = 2$ 对应 95.5% 置信区间）。

**结果**：以 $(1 - \delta_c)$ 的概率，真实扰动落在估计集合内，RCBF 安全保证以相同概率成立。

## 五、整体框架：SAC-RCBF

### 5.1 架构图解

```
状态 x
    │
    ▼
┌─────────────────┐
│   SAC 策略网络   │  输出原始控制动作 u^RL（可能不安全）
└────────┬────────┘
         │ u^RL
         ▼
┌─────────────────┐     ┌──────────────────────┐
│  RCBF-QP 安全层  │ ◄── │ GP 扰动估计 D(x)      │
│  求解补偿量 u^S  │     └──────────────────────┘
└────────┬────────┘
         │ u^S
         ▼
    u* = u^RL + u^S   ← 最终安全控制输入
         │
         ▼
      环境执行
```

### 5.2 RCBF-QP 的形式

安全层求解以下二次规划问题：

$$
(u^S, \epsilon_s) = \arg\min_{u, \epsilon} \|u\|^2 + l\epsilon_s^2
$$

$$
\text{s.t.} \quad \nabla h_i^\top [f(x) + g(x)(u + u^{RL})] \geq -\alpha(h_i(x)) - \min \nabla h_i^\top \Psi(x) + \epsilon_s, \quad \forall i
$$

关键设计：
- **目标函数**：最小化补偿量 $u^S$ 的范数，即对 RL 输出的**最小修正**；
- **松弛变量** $\epsilon_s$：当所有约束同时满足不可能时（QP 不可行），允许有限度的约束违反，以大惩罚系数 $l$ 压制；
- **最终控制**：$u^* = u^{RL} + u^S$，RL 输出与安全补偿叠加。

## 六、提升训练效率的两项机制

### 6.1 可微分安全层（核心创新）

**问题根源**：在朴素的"SAC + CBF 过滤层"组合中，SAC 的策略梯度更新基于 $u^{RL}$ 计算，但实际执行的是 $u^* = u^{RL} + u^S$。安全层的修改对 SAC 来说是"不透明的"，相当于环境动力学发生了突变，使得 Q 函数难以准确学习，尤其在靠近安全边界时修改幅度大，造成训练不稳定。

**解决方案**：利用可微分优化框架（OptNet / cvxpylayers），通过 QP 的 KKT 条件推导梯度，使策略梯度**直接对 $u^*$ 反传**，而非对 $u^{RL}$。

修改后的 SAC 损失函数变为（以 Critic 损失为例）：

$$J_Q(\theta) = \mathbb{E}\left[\frac{1}{2}\left(Q_\theta(x_t, u^{RL}_t + u^S_t) - (r(x_t, u^{RL}_t + u^S_t) + \gamma \mathbb{E}[V_{\bar\theta}(x_{t+1})])\right)^2\right]$$

即奖励和 Q 值的计算都基于实际执行的安全动作 $u^* = u^{RL} + u^S$，而非 RL 的原始输出。

**效果**：当安全层大幅修改 RL 输出时（如接近障碍物时），SAC 能感知到这种修改并调整策略，而不是盲目输出被大量修正的不安全动作。

### 6.2 基于模型的合成数据生成

当奖励函数和安全约束已知时，可以利用 GP 学到的局部动力学模型生成短视程（short-horizon）的合成轨迹，加入经验回放缓冲区，进一步提升样本效率。这是标准 Model-Based RL 的思路，在此作为可选的加速手段。

## 七、约束无关任务学习（零样本迁移）

### 7.1 问题：训练约束污染价值函数

考虑一个场景：训练时需要避开 A、B 两个障碍物，测试时换成 C、D。如果直接用 SAC-RCBF 训练，Q 函数会在 A、B 障碍物周围学到极低的价值（因为安全层在那里频繁大幅修改动作，导致奖励受损）。迁移到新障碍物配置后，这些学到的"低价值区域"完全无效，反而阻碍新环境中的策略搜索。

### 7.2 解决方案：只在计算 cost-to-go 时忽略安全层

修改 Bellman 方程，在计算**未来步骤**的价值时，假装安全层不存在（令 $u^S_{t+1} = 0$），但当前步仍使用真实的 $u^* = u^{RL} + u^S$：

$$J_Q(\theta) = \mathbb{E}\left[\frac{1}{2}\left(Q_\theta(x_t, u^{RL}_t + u^S_t) - (r_t + \gamma \mathbb{E}[V^{mod}_{\bar\theta}(x_{t+1})])\right)^2\right]$$

其中 $V^{mod}$ 的计算中令所有未来的 $u^S = 0$。

**直觉**：Q 函数学习的是"不考虑当前训练约束时，到达各个状态的内在价值"，这个价值与具体障碍物配置无关，因此可以迁移。安全性由实时的 RCBF-QP 层保证，价值函数只负责学习任务本身。

## 八、实验验证

### 8.1 实验一：样本效率对比

**独轮车导航**（unicycle，到达目标点同时避障）：
- MB SAC-RCBF（用合成数据）> MF SAC-RCBF > 两个 baseline
- 此环境中可微分安全层收益有限（障碍物是圆形，安全层行为平滑）

**车队跟驰**（car following，5辆车保持安全距离）：
- MB 和 MF SAC-RCBF 均显著优于 baseline
- 不加可微分安全层的 baseline 多次无法收敛到有意义策略
- 证明：安全层行为不平滑时，可微分安全层至关重要

全程无安全违反（RCBF 值始终 $\geq 0$）。

### 8.2 实验二：零样本迁移

- 训练于固定障碍物配置，测试于 200 个随机障碍物配置
- Constraint-Agnostic SAC-RCBF 完成率 63%，普通 SAC-RCBF 仅 17%
- PVTOL（2D 四旋翼）环境：63% vs 52%，提升约 33%

## 九、局限性与未来方向

论文本身承认的局限：

1. **GP 的扩展性**：GP 计算复杂度为 $O(N^3)$，在高维状态或大样本量时计算开销显著，可能成为实时控制瓶颈；
2. **级联 RCBF 的理论缺失**：对于 relative degree $\geq 2$ 的障碍函数（如车队跟驰中的 $h_i$），论文用了级联 RCBF 处理，但"理论细节留待后续工作"；
3. **安全违反的概率性**：RCBF 提供的是 $(1-\delta_c)$ 概率的安全保证，而非 100% 确定性保证（因为 GP 估计存在置信区间）；
4. **仅做仿真验证**：两个实验均在自定义仿真环境中完成，无物理平台验证。

## 十、对本课题的直接启示

| Emam 框架的组件 | 对应到履带车课题的问题 |
|----------------|----------------------|
| 标称模型 $f(x), g(x)$ 已知 | 需要建立含滑移的履带车运动学方程作为标称模型 |
| GP 学习扰动 $d(x)$ | GP 需估计左右履带独立滑移引起的扰动，状态维度可能较高 |
| RCBF 设计 | 横摆角速度、滑移率等约束的 relative degree 需逐一分析 |
| 可微分安全层 | 若安全层修改幅度大（如滑移率临界工况），此机制对训练稳定性至关重要 |
| 约束无关学习 | 若希望在不同路面工况间迁移，此机制有价值 |
| GP 计算瓶颈 | 履带车实时控制频率要求高，需评估 GP 推理时延是否可接受 |
