# 基于MPC与控制屏障函数的履带车安全路径跟踪控制方法研究

# 一、研究背景

履带车辆因其优异的地面通过性和承载能力，广泛应用于工程机械、农业装备、野外勘探、灾害救援和军用平台等对地形适应性要求较高的场景。然而，履带与地面之间复杂的接触力学使得履带车动力学行为呈现出强非线性、强耦合和参数时变特性。在松软路面、低附着路面及崎岖地形等复杂工况下，履带与土壤之间会不可避免地产生纵向滑移和横向侧滑，导致实际轨迹与期望路径产生偏差，严重时引发控制失稳。

履带车路径跟踪任务中同时存在多种必须显式处理的安全约束：横摆角速度限制（防止过度转向引发侧翻）、单侧履带滑移率上限（保持牵引力可控）、执行器力矩饱和约束，以及控制量变化率限制（保护机构安全）。这些约束的特殊之处在于，它们不是性能指标的一部分，而是必须在任意时刻强制满足的安全边界——一旦违反，可能造成不可逆的安全事故。

因此，履带车路径跟踪控制问题的核心挑战集中于两个层面：**其一，如何在滑移参数时变、地面条件不确定的情况下保持路径跟踪精度；其二，如何对上述多类安全约束提供逐点（point-wise）硬保证，而非依赖软性惩罚项的间接调节。** 现有方法在这两个层面均存在明显局限，亟需探索新的融合框架。

# 二、国内外研究现状

## 2.1 履带车路径跟踪控制：滑移问题与现有方法的局限

履带车路径跟踪控制的核心障碍是履带-地面接触引发的滑移问题。Zhao等人（Journal of Field Robotics, 2025）指出，在湿地、泥泞等复杂工况下，强时变的滑移会显著降低路径跟踪精度；Yan等人（Actuators, 2025）进一步指出，越野环境中地面附着条件的复杂性与外部扰动，使传统路径跟踪控制性能严重下降，履带与地面之间不确定的滑移率-驱动力关系放大了理想模型与实际响应之间的差异。

针对滑移问题，现有研究沿两条路线展开。**第一条路线**是通过状态估计对滑移参数进行在线辨识与补偿。Zhao等人（2025）提出基于变分贝叶斯扩展卡尔曼滤波（VBEKF）的方案，通过学生t分布重建非高斯测量噪声，将最大横向跟踪误差降低约30%；Yan等人（2025）将滑移视为广义外部扰动，设计滑移因子观测器并结合超螺旋滑模控制实现补偿。然而，上述方法存在共同的根本性局限：滑移参数的准确估计依赖相对可靠的运动学模型假设，而滑移本身又是导致模型不准的根源，形成循环依赖；在地面条件急剧变化时，估计算法的收敛速度难以保证。

**第二条路线**是模型预测控制（MPC）。Li等人（Ocean Engineering, 2023）针对水下履带推土机建立了含滑移参数的非线性运动学模型，提出MPC-CSS（考虑滑移与控制平滑）策略，相比纯追踪控制使横向稳定性提升72.5%，验证了MPC在履带车滑移工况下的有效性。Liu等人（IET ITS, 2024）的研究同时揭示了MPC的核心矛盾：当路面附着系数从高附着（μ=0.8）切换为低附着（μ=0.3）时，固定参数MPC因模型失配出现失稳行为——MPC的预测精度依赖于模型参数的实时准确性，而这恰恰是滑移工况下难以保证的。

**两条路线的共同盲区**在于安全约束的处理方式。无论是滑移补偿控制器还是MPC，均将横摆角速度、滑移率等约束作为代价函数中的软性惩罚项处理，无法提供逐点硬保证。在实际工况中，一次约束违反（如短暂侧翻）即可造成不可挽回的后果，软约束的统计意义上的满足远不足够。

## 2.2 控制屏障函数（CBF）理论

控制屏障函数（Control Barrier Function, CBF）由Ames等人系统化提出（IEEE TAC, 2017），其核心思想是将安全集合的前向不变性转化为对控制输入的实时线性不等式约束。对于由超水平集定义的安全集合 $\mathcal{C} = \{x : h(x) \geq 0\}$，若存在扩展类K函数 $\alpha$ 使得对所有 $x \in \mathcal{C}$ 满足 $\dot{h}(x,u) + \alpha(h(x)) \geq 0$，则称 $h$ 为控制屏障函数。通过在每个时间步求解一个二次规划（CBF-QP），可将任意名义控制输入修正为满足CBF约束的最近点，以最小修正量保证系统在安全集合内演化。

Ames等人进一步将CBF与控制Lyapunov函数（CLF）结合，在统一的CLF-CBF QP框架中协调稳定性目标与安全约束，在自适应巡航控制和车道保持问题上得到验证。CBF方法的核心优势在于**对安全性的逐点（point-wise）硬保证**，这是软约束方法从原理上无法实现的。

然而，CBF方法也存在明显局限：其一，CBF条件依赖系统的精确动力学模型——当模型存在不确定性（如滑移引起的参数偏差）时，CBF的安全保证可能失效或变得过于保守；其二，CBF仅保证安全性，本身不提供对路径跟踪性能的优化，需要与性能导向的名义控制器（如MPC）配合使用；其三，针对多约束场景，多个CBF约束的相容性（feasibility）需要专门分析。

## 2.3 MPC与CBF的融合：现有工作与不足

将MPC与CBF结合的研究近年来开始出现。一种思路是将CBF约束直接嵌入MPC的滚动优化问题，形成CBF-MPC框架：MPC负责多步预测和性能优化，CBF约束确保每步预测轨迹的安全性。另一种思路是"MPC作为名义控制器 + CBF-QP作为安全过滤层"的分层架构，两者解耦设计，CBF层对MPC输出进行实时最小修正。

然而，现有MPC与CBF融合研究主要集中于轮式车辆、无人机等场景，存在以下不足：**其一**，针对履带车差速驱动机构，如何将滑移率约束、横摆角速度约束等履带特有的物理约束转化为有效的CBF形式，尚无系统性工作；**其二**，当MPC的预测模型因滑移导致参数失配时，CBF安全层如何保持鲁棒性，现有框架缺乏针对性设计；**其三**，MPC优化目标与CBF安全约束之间可能存在冲突（feasibility问题），在履带车多约束场景下的协调机制尚未得到研究。

# 三、存在的问题与研究空白

**（1）MPC预测模型在滑移工况下的参数失配问题**

Liu等人（2024）已证明，MPC在路面附着系数变化时因模型失配出现严重性能下降。Li等人（2023）通过引入滑移参数的运动学模型缓解了这一问题，但其模型中的滑移参数仍需在线估计，在非高斯噪声或急剧变化的地面条件下估计精度难以保证。如何设计对滑移参数不确定性具有鲁棒性的MPC预测模型，是尚未解决的问题。

**（2）现有控制方法对安全约束仅提供软性保证**

无论是传统PID、滑模控制，还是MPC和基于观测器的补偿方法，均将横摆角速度、滑移率等约束作为软性惩罚项处理，无法对每一控制时间步提供确定性的安全保证。在履带车实际作业中，约束违反（如侧翻、打滑失控）具有不可逆性，软约束的统计保证在安全关键场景下存在根本性隐患。

**（3）面向履带车特性的CBF设计空白**

现有CBF理论及其工程应用集中于轮式车辆和一般机器人系统，未能体现履带车差速驱动、单侧滑移率耦合等本质特征。履带车的约束结构与轮式车辆存在本质差异：滑移率不仅影响牵引力，还直接耦合进入转向运动学方程，这要求CBF函数形式与轮式车辆的设计方法有所不同。目前，针对履带车特性的CBF函数体系设计，尚属空白。

**（4）MPC与CBF融合的可行性保证问题**

当MPC优化与CBF约束同时作用于控制系统时，两者之间可能存在相互冲突导致QP不可行的情况，尤其是在多约束同时趋近边界时。现有研究缺乏针对履带车多约束场景下MPC-CBF框架可行性的系统分析与保障机制。

# 四、研究目标

本研究面向复杂工况下履带车路径跟踪控制任务，拟提出一种基于MPC与控制屏障函数的分层安全控制方法，核心目标如下：

1. 建立考虑左右履带独立滑移的运动学与简化动力学模型，在MPC预测模型中显式引入滑移参数，并研究滑移参数不确定性对MPC预测精度和控制性能的影响机制；

2. 针对履带车横摆角速度限制、单侧滑移率约束、执行器饱和及控制变化率约束，设计体现履带差速驱动特性的控制屏障函数体系，并证明各CBF的有效性；

3. 构建"MPC性能层 + CBF-QP安全层"的分层控制架构，通过CBF安全过滤层对MPC输出进行实时最小修正，实现对所有约束的逐点硬保证；

4. 针对MPC与CBF可能存在的优化冲突，设计可行性保障机制（如软化CBF约束的优先级策略或备用安全控制律），保证闭环系统在极端工况下的鲁棒性；

5. 在仿真平台上进行系统性验证，与传统MPC、滑模控制+滑移观测器及无安全层的MPC方案进行定量对比。

# 五、研究内容

## 5.1 含滑移的履带车动力学建模

建立适用于MPC预测与CBF分析的履带车模型。在运动学层面，参考Li等人（2023）和Zhao等人（2025）的建模思路，采用考虑左右履带独立滑移的差速运动学模型：引入左右履带纵向滑移率（$i_L, i_R$）和横向侧滑角（$\beta$）作为滑移参数，建立含滑移的位姿运动学方程。在动力学层面，建立双侧履带驱动力与转向阻力矩的耦合方程，为CBF中滑移率约束的设计提供动力学依据。

针对MPC的应用需求，研究将上述非线性模型在工作点附近线性化的方法，以及在滚动预测框架中如何处理滑移参数的时变不确定性（如采用区间参数或鲁棒预测）。

## 5.2 基于MPC的路径跟踪名义控制器

以上述含滑移的运动学模型为预测模型，设计面向路径跟踪的MPC控制器。状态变量包含横向误差、航向误差、纵向速度误差；控制输入为双侧履带驱动力矩。代价函数权衡路径跟踪精度与控制平滑性。

本部分重点研究两个问题：其一，MPC预测时域和控制时域的选取对滑移工况下跟踪性能的影响；其二，参考Li等人（2023）的MPC-CSS策略，在代价函数中增加控制平滑性惩罚项，降低控制输入突变率，为后续CBF约束留出更大的可行域空间。此阶段输出的是"不带硬约束保证"的名义控制律，作为后续CBF安全层的输入。

## 5.3 面向履带车约束特性的CBF函数体系设计

这是本研究最核心的创新工作。针对履带车控制中的多类安全约束，分别设计对应的控制屏障函数 $h_i(x)$：

**（1）横摆角速度约束CBF**：构建 $h_{\text{yaw}}(x) = r_{\max} - |r|$，利用履带车差速转向的运动学关系，将该约束转化为对左右履带驱动力差的实时线性不等式，防止转弯速率超限引发侧翻。

**（2）单侧滑移率约束CBF**：基于履带-地面接触力学，设计反映左右履带滑移率上限的屏障函数 $h_{i_L}(x), h_{i_R}(x)$。与轮式车辆的侧偏约束不同，此处需处理滑移率与驱动力矩之间的非线性耦合关系，这是本部分区别于现有CBF设计工作的关键点。

**（3）执行器饱和CBF**：针对左右履带驱动力矩的上下限约束，构建输入约束对应的CBF，避免执行器进入饱和区导致控制能力丧失。

**（4）控制变化率约束**：以控制输入变化量为扩展状态变量，设计限制控制指令突变率的CBF，保护传动机构安全并改善控制平滑性。

各CBF约束以零化屏障函数（Zeroing CBF）形式转化为线性不等式约束，汇入统一的CBF-QP问题，实现多约束的联合处理。同时，分析多个CBF约束同时激活时的相容性条件，为可行性保障机制的设计提供理论基础。

## 5.4 MPC-CBF分层控制架构与可行性保障

将MPC名义控制器与CBF-QP安全层整合为分层架构：MPC在每个控制步输出名义控制输入 $u_{\text{MPC}}$，随后通过CBF-QP安全过滤层求解实际控制输入 $u^*$：

$$u^*(x) = \arg\min_{u} \|u - u_{\text{MPC}}\|^2$$
$$\text{s.t.} \quad \dot{h}_i(x,u) + \alpha_i(h_i(x)) \geq 0, \quad \forall i; \quad u \in \mathcal{U}$$

**可行性保障机制**是本部分的创新点。当多个CBF约束同时趋近边界时，上述QP可能不可行。本研究拟采用以下策略：引入松弛变量 $\delta_i \geq 0$ 软化部分CBF约束，并在目标函数中以大权重惩罚松弛量，使系统在极端情况下优先满足高优先级约束（如防侧翻）而允许低优先级约束（如控制平滑性）有限度地退让。同时，从理论上分析该软化机制下系统的安全性边界。

## 5.5 仿真验证与对比分析

在仿真平台（MATLAB/Python）中搭建包含典型路面工况（坚实路面μ=0.8、松软路面μ=0.4、变附着工况）和典型路径（直线、圆弧、S形曲线）的评测环境。

对比方案：
- 基准MPC（无安全层，固定滑移参数）
- MPC-CSS（参考Li等人2023，含滑移参数的MPC，无CBF）
- 滑移观测器+滑模控制（参考Yan等人2025）
- **本文方法：MPC + CBF-QP安全层**

评价指标：路径跟踪精度（$\text{RMSE}_y$、$\text{RMSE}_\psi$）、约束违反率（各约束分项统计）、控制平滑性（控制输入变化率均值）、滑移参数扰动下的鲁棒性。

# 六、主要创新点

**（1）针对履带车差速驱动与滑移耦合特性，设计多类控制屏障函数体系**

现有CBF设计工作集中于轮式车辆和无人机，未能体现履带车的本质特征。本研究针对履带差速转向机构，设计横摆角速度、单侧滑移率、执行器饱和及控制变化率四类CBF函数，建立面向履带车特性的安全集合体系。特别地，滑移率CBF的设计需处理滑移率与驱动力矩之间的非线性耦合，在方法上区别于现有轮式车辆的CBF设计。

**（2）提出MPC-CBF分层控制架构，实现路径跟踪性能与安全约束的解耦保证**

现有履带车控制方法（包括MPC）均以软约束处理安全限制。本研究通过"MPC性能层+CBF-QP安全层"的分层架构，将性能优化与安全保证解耦：MPC专注路径跟踪性能，CBF安全层以最小控制修正量保证约束在每一时间步的逐点满足。该架构使两个组件均可独立设计和调试，工程可实现性强。

**（3）面向多约束履带车场景的CBF可行性保障机制**

多约束同时激活时CBF-QP的可行性是现有研究较少系统处理的问题。本研究针对履带车多约束共存场景，设计基于优先级松弛的可行性保障机制，在理论上分析各约束优先级划分的依据，并证明在该机制下系统的安全性边界，为多约束CBF的工程应用提供系统性方法。
