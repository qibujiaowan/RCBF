## 真实的工程问题（从实验室实际数据中挖掘）

**平台信息**：
- 项目：重型履带车越野无人驾驶
- 实验平台：真实履带车（双电机独立驱动）
- 当前算法：传统MPC
- 控制量：上层输出转速差 → 底盘控制器转换为转矩 → 双电机执行

**真实问题**：
- 车速10m/s越野行驶，底盘响应延迟1s+（MPC只显式补偿了0.2s）
- MPC航向角误差权重过大 → 相邻控制周期转速差剧烈跳变 → 底盘控制器无法跟上
- 大曲率弯道跟踪误差达**5m**级别
- 弯道出现履带车冲出轨迹、**MPC QP求解失败、需人工介入**的情况
- 怀疑根本原因：上层控制器输出的激进指令与底盘执行器实际能力严重失配

**问题本质（引导对话得出）**：
> 重型履带车在高速越野场景下，上层控制器输出的激进指令与底盘执行器实际能力之间存在严重失配，导致弯道跟踪误差达5m级别、QP求解失败需人工介入。

## 待确认的关键事项

1. **延迟来源**：用户尚未详细分析数据，怀疑是电机转速响应延迟（底盘控制器对大转速差指令有限速/平滑处理）
2. **问题是否已被解决**：用户尚未检索相关文献，"可能已被解决"是一拍脑袋的判断，未经验证

## 下一步行动：文献检索方向

用户计划检索以下方向，判断这个真实问题是否已有人系统研究：

1. `tracked vehicle high speed path tracking` + `actuator delay` 或 `input delay`
2. `MPC input constraints` + `actuator saturation` + `tracked robot`
3. `large delay compensation MPC` + `mobile robot`

检索后用三个框架判断研究价值：
- 这个平台组合（重型履带车+高速+越野+受限执行器）学术界有没有人研究？
- 问题能否分解成有层次的、各自有理论深度的子问题？
- 解决方法有没有迁移到一类系统（大延迟+受限执行器移动机器人）的价值？

## Why：对原课题的影响

原SAC-RCBF课题框架建立在"滑移是核心挑战"的假设上，但实验室真实数据显示核心挑战是**执行器能力失配+大延迟**。两个问题性质不同，解决方案路线也不同。检索结果将决定是修补原框架还是重构研究问题。
